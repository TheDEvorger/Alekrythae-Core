# Security Policy

## Supported version

Security fixes are currently applied to the latest public release only.

## Reporting a vulnerability

Please report vulnerabilities privately to:

**thedevorger.alekrythae.dev@gmail.com**

Include the affected component, reproduction steps, impact and a minimal proof of concept. Do not publish account data, private world data, credentials or destructive exploit instructions.

There is currently no bug-bounty programme. Responsible reports may be acknowledged at the Licensor's discretion.
