# Ałek’ryŧhæ Core v0.1.2

A compatibility-focused Core update centered on persistent, adapter-aware GPU selection for `.alek` applications.

## Highlights
- Automatic strongest-GPU selection when no manual choice exists.
- Persistent manual GPU selection across launches.
- High-performance WebView2/Chromium GPU hint for discrete adapter selection.
- Backward-compatible graphics bridge for existing `.alek` applications.
- Saved GPU choice is retained if an adapter is temporarily unavailable.
- Existing `.alek` host, storage, media, DeveloperBridge, window and lifecycle contracts remain unchanged.

## Download
Use `Alekrythae-Core-v0.1.2-Windows-x64.zip` for the ready-to-run Windows x64 build.

The release build is self-contained; end users do not need to install the .NET SDK.
